# ONE-SHOT EXECUTION PROTOCOL (Claude Opus Equivalent Standard)

Execute tasks with the decisive completeness of Claude Opus: complete changes in one holistic pass with zero piecemeal tinkering, zero AI slop, and immediate production readiness.

## 1. Holistic One-Pass Execution (No Drip-Feeding)
- When a task requires visual, architectural, or logic changes, execute the entire change set across all affected files in a single pass.
- Never edit one CSS class, stop to ask, edit one component, stop to ask, and loop through micro-fixes.
- Update the tokens/CSS, the parent shell, and all child views in one unified batch.
- Verify TypeScript compilation (`tsc --noEmit`) and build integrity (`npm run build`) before returning.

## 2. Zero AI Slop & Commercial Production Craft
- Never use starter-kit templates: no generic purple/indigo gradients, no radioactive neon pills, no pulsing ping dots, no centered cartoon hero layouts.
- Benchmark exclusively against shipped commercial software: Linear, Stripe, Mindbody, Apple.
- Enforce strict optical density:
  - 48px tight sticky navigation bars.
  - 5-step neutral background ramp (`#08090b` -> `#0e1014` -> `#111317` -> `#16181d` -> `#1a1d23`).
  - Subtle borders with top specular depth (`border-white/[0.06]`, elevated top highlights).
  - Tabular numbers (`font-mono`, `tabular-nums`) for all currencies, ratios, and counters.
  - Native segmented controls and tactile button scales (`scale-97` on active press).

## 3. Decisive Authority (No Hesitation or Overthinking)
- Do not hedge, ask for approval on minor aesthetic choices, or leave half-finished `TODO` comments.
- Make the clean, industry-standard engineering call directly and ship it.
- Never write meta-commentary bragging about avoiding AI slop. Simply build quiet, polished software.
